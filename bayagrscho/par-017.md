# § 17 Nachholen von Leistungsnachweisen
(1) Versäumen Studierende einen angekündigten Leistungsnachweis mit ausreichender Entschuldigung, so erhalten sie einen Nachtermin. Versäumen Studierende mehrere angekündigte Leistungsnachweise mit ausreichender Entschuldigung, so kann ein Nachtermin für mehrere Leistungsnachweise angesetzt werden. Der Nachtermin ist den Studierenden mindestens eine Woche vorher mitzuteilen.
(2) Wird der Nachtermin mit ausreichender Entschuldigung versäumt, so kann eine Ersatzprüfung angesetzt werden. Eine Ersatzprüfung kann in einem Fach nur einmal im Semester oder Schulhalbjahr stattfinden. Sie kann sich über den gesamten bis dahin behandelten Unterrichtsstoff des Semesters oder Schulhalbjahres erstrecken. Der Termin der Ersatzprüfung und der Prüfungsstoff sind den Studierenden spätestens eine Woche vorher mitzuteilen.
(3) Nehmen Studierende an der Ersatzprüfung wegen Erkrankung nicht teil, so muss die Erkrankung durch ärztliches Zeugnis nachgewiesen werden. Die Schule kann die Vorlage eines amtsärztlichen Zeugnisses verlangen.
